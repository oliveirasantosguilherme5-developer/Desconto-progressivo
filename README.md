# Sistema de Desconto Progressivo

Programa simples em Python que calcula o desconto de uma compra de acordo com o valor total gasto.

## Como funciona

O usuário digita o valor da compra e o programa aplica um desconto conforme a faixa de valor:

| Valor da compra | Desconto |
|---|---|
| Menor que R$ 200,00 | 5% |
| De R$ 200,00 até R$ 299,99 | 10% |
| A partir de R$ 300,00 | 15% |

No final, o programa mostra o percentual de desconto ganho e o valor final a pagar.

## Como executar

1. Tenha o Python instalado no computador.
2. Salve o código em um arquivo chamado `desconto.py`.
3. No terminal, digite:

\```
python desconto.py
\```

4. Digite o valor da compra quando for solicitado.
